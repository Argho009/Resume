# AC Portfolio — My Life

An epic Japanese zen garden themed portfolio website with interactive tree navigation, falling sakura petals, and glassmorphism UI.

## Pages

- **/** — Home / Journey (interactive tree hub)
- **/skills** — Skill Ecosystem
- **/projects** — Selected Works
- **/experience** — Professional Experience
- **/certificates** — Achievements & Certificates
- **/education** — Academic Foundation

## Run Locally

```bash
cd portfolio
npm install
npm run dev
```

Open http://localhost:5173

## Build for Production

```bash
npm run build
npm run preview
```

## Customize Content

Edit `src/data/portfolio.ts` with your real name, projects, experience, certificates, and education details.
